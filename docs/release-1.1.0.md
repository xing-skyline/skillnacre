# SkillNacre · 技能匣 1.1.0

面向 Windows x64 的首个公开版本。中文界面与文档，支持选择技能主源、自动识别 AI 工具路径，并通过真实目录软链接统一管理技能。

## 下载后开始使用

日常使用选择 `SkillNacre-Setup-1.1.0.exe`；免安装启动选择 `SkillNacre-Portable-1.1.0.exe`。两者都不需要 Node.js 或 Python。校验值见发行附件 `SHA256SUMS.txt`。

打开软件后：**切换来源 → 自动识别路径 → 勾选技能 → 连接到 AI 工具 → 预览并确认**。

完整步骤见[中文使用说明](https://github.com/xing-skyline/skillnacre/blob/main/docs/使用说明.md)。

## 主要功能

- 主源可选择 CC Switch、AI 工具目录或自定义文件夹；预置 11 类工具并支持自定义路径。
- 自动识别常见路径、环境变量、Hermes profiles、OpenClaw / OpenCode 路径配置，展示候选依据后应用。
- 技能搜索、分类、收藏、Markdown 阅读、源文件编辑和资源预览。
- 批量生成真实目录软链接，保存技能组合，通过连接矩阵查看状态。
- 本地目录与公开 GitHub 导入、来源追踪、提交记录、更新检查与差异预览。
- 同步盘本机目录双向手动同步、共同基线和明确的冲突选择。
- 操作前备份、程序内恢复、副本恢复以及中断日志整理。

## 名称与兼容

早期本地版本名为 SkillDock；为减少同类项目名称混淆，本版使用 **SkillNacre · 技能匣**。

应用数据继续使用 `%APPDATA%\skilldock`，以保留历史恢复记录中的绝对路径。既有主源、备份和工具路径继续保留。新安装不预填个人备份目录，由使用者自行选择。便携版也使用此应用数据位置。

## 当前限制

- Windows x64 构建尚未使用发布者证书签名，系统可能提示未知发布者。创建软链接通常需要开启开发者模式。
- “找到目录”“已连接”属于文件系统状态，不等于目标工具的某次会话已经加载技能。
- Codex 同时保留兼容目录；新环境请核对官方 `~/.agents/skills` 位置。
- 仅支持公开 GitHub 仓库；导入不执行技能脚本、不安装其依赖。
- 本版没有 macOS / Linux 发行包、项目工作区自动发现、统一 CLI、跨电脑恢复包或软件自动更新。
